# REPLIT - HOSTING GRATUITO QUE FUNCIONA

## Pasos exactos:

### 1. Registro
- **replit.com** → Sign up
- Login con Google/GitHub

### 2. Crear Repl
- "Create Repl"
- "Import from GitHub"
- Pegar URL de tu repo

### 3. Configurar
- Crear archivo `.env` 
- Agregar variables de BD

### 4. Ejecutar
- Click "Run"
- Replit instala dependencias automáticamente

### 5. Base de datos
- Usar SQLite (incluido)
- Variables automáticas

**Replit funciona 100% gratis sin tarjeta**
